# 个人学习笔记网站（带后台管理）

一个零依赖的静态个人网站，附带本地后台管理界面。

## 怎么运行（两种方式）

### 方式一：双击启动（推荐）

在 Finder 里找到 `personal-site` 文件夹，双击里面的 **启动网站.command** 文件。

如果提示无法打开，右键点击它 → 选择「打开」→ 再点「打开」。

启动后会自动打开浏览器进入管理后台。

### 方式二：用终端启动

```bash
cd personal-site
python3 admin.py
```

然后访问：

- 管理后台 http://localhost:8000/admin
- 网站首页 http://localhost:8000

## 怎么更新内容

1. 打开管理后台（上面的地址）
2. 点「＋ 新建文章」
3. 填写标题、分类、日期、摘要和正文
4. 点「保存并更新网站」——首页和文章页会自动生成

也可以在文章列表里点「编辑」或「删除」来管理已有文章。

## 修改网站名称和简介

后台管理页面往下翻，有一个「⚙️ 网站设置」区域：

- **你的名字**：显示在首页 logo 和「关于我」区域
- **网站名称**：显示在浏览器标签页和页脚
- **首页大标题**：首页最大的那行字，换行会自动分行
- **网站简介**：首页大标题下方的介绍文字

改完点「保存网站设置」，全站（首页 + 所有文章页）自动更新。

正文支持的简单格式：

- `## 二级标题`、`### 三级标题`
- `**粗体**`、`` `代码` ``
- `- 列表项`、`1. 编号列表`
- `> 引用`
- 三个反引号包裹的代码块
- `| 表格 | 用竖线 |`

## 不启动后台也能看网站

直接双击 `index.html` 就能在浏览器里查看网站（只读预览）。
要编辑内容，还是需要用上面的方式启动后台。

## 目录结构

```
personal-site/
├── 启动网站.command       # 双击启动后台
├── admin.py              # 后台管理程序
├── posts.json            # 所有文章的数据（在这里编辑内容）
├── index.html            # 首页（文章卡片自动生成）
├── posts/                # 文章页面（自动生成）
├── css/style.css         # 样式
├── js/main.js            # 主题切换
└── README.md
```

## 如何部署到网上（免费）

### GitHub Pages

1. 在 GitHub 创建一个仓库，比如 `my-blog`
2. 把 `personal-site` 里的所有文件上传到仓库
3. 仓库 Settings → Pages → Source 选 `main` 分支
4. 稍等一分钟，访问 `https://你的用户名.github.io/my-blog`

### Vercel / Netlify

1. 注册账号并连接 GitHub 仓库
2. 导入仓库，直接部署（无需任何构建配置）

部署后网站就是静态文件，访客不会看到后台。
以后更新内容：本地启动后台改好 → 把改动的文件上传到仓库 → 自动更新。

## 上传 GitHub 后，别人能进入后台吗？

**不能，放心。**

原因：

- 这个后台是一个需要 Python 运行的本地程序，只在你自己的电脑上启动
- GitHub Pages / Vercel / Netlify 只提供静态文件托管，不会运行 Python
- 访客访问你的网站时，`/admin` 这个地址根本不存在，会显示 404
- `admin.py` 传上去只是仓库里的一份代码文件，别人能看到代码但无法运行它

所以你可以把整个 `personal-site` 文件夹（包括 `admin.py`、`posts.json`）一起上传：
- 好处是换电脑时克隆仓库就能继续用后台编辑
- `posts.json` 里的内容就是你的文章正文，本来就是公开内容，没有隐私风险

如果你希望仓库更干净，也可以不上传 `admin.py` 和 `启动网站.command`，
但建议保留 `posts.json`（它是文章的源数据，丢了以后就没法在后台里编辑了）。

- 站点名称：搜索 `迟雨` 全局替换成你的名字
